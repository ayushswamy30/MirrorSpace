Installing the early access app

  1. On your Android phone, tap Download the app above.
  2. Open the downloaded file. If Android asks, allow your browser to install apps — you can switch this off again afterwards.
  3. Tap Install, then open Lowkei.

Only install Lowkei from this site. If you got the file anywhere else, delete it and download it here.

What you’ll need

  • An Android phone running Android 8.0 or newer.
  • To read sleep, steps or heart rate: Health Connect, which is built into Android 14 and available from the Play Store for older versions. It’s optional.
  • To use the Mirror: an internet connection. Everything else works offline.
